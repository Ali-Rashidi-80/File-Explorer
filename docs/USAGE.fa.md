# راهنمای استفاده

**زبان‌ها:** [English](USAGE.md) · **فارسی**

## اجرا

```bat
pip install -r requirements.txt
python file-explorer-pyside6.py
```

یا پس از بیلد: `dist\FileExplorer_Portable.exe`.

## تب کاوش

1. **حالت** را انتخاب کنید: کامل یا فقط ساختار.
2. **فرمت** را انتخاب کنید: TXT همیشه؛ JSON فقط در حالت ساختار.
3. پوشه را انتخاب یا Drag & Drop کنید.
4. **شروع اسکن** را بزنید.
5. نوار پیشرفت و درخت زنده را ببینید.
6. از منو کپی یا ذخیره کنید.

### حالت کامل چه می‌نویسد

- فایل متن‌مانند زیر ۱۰ مگ ← محتوا
- متن خیلی بزرگ ← اخطار، بدون محتوا
- باینری ← نشانگر باینری
- عبور از ۵۰ مگ تجمعی ← توقف با پیام سقف

### حالت ساختار

- **TXT:** سربرگ + درخت `├──` / `└──`
- **JSON:** اشیاء تو در توی `{name, type, children}`

## تب بازسازی

1. نقشه TXT/JSON را انتخاب کنید.
2. پوشه خروجی را مشخص کنید.
3. بازسازی را شروع کنید.

> **حد صادقانه:** محتوای فایل‌ها بازگردانی **نمی‌شود**؛ فقط پوشه و فایل خالی.

## منوها

| منو | کارها |
|-----|--------|
| فایل | انتخاب پوشه، ذخیره، خروج |
| ویرایش | کپی کل، پاکسازی ادیتور |
| کمک | درباره (خلاصه v5.1) |

## نکات

- برای اسکلت ماشین‌خوان: **JSON ساختار**.
- برای زمینه LLM: **TXT کامل** — روی مونوریپوی بزرگ سقف ۵۰ مگ را در نظر بگیرید.
- قبل از اشتراک نقشه، اسرار (مثلاً `.env`) را بررسی کنید.
